# 한국어 발화 종료 감지 평가 · EOT 리더보드

김지훈 · 202220760

- 개인 저장소: [gimghoon/speech_leaderboard](https://github.com/gimghoon/speech_leaderboard)
- 리더보드 사이트: [EOT Bench](https://gimghoon.github.io/speech_leaderboard/?v=26b37b0)

한국어 은행 문의 음성에서 사용자가 말을 마친 시점을 얼마나 정확하고 빠르게 판단하는지 비교합니다.
무음 타이머와 공개 사전학습 모델 2종을 평가했으며, 추가 학습은 하지 않았습니다.

## 처음 시작하기

[처음 실행해보기](docs/first-run.md)를 따라 환경 준비 → Smart Turn 실제 추론 → 예측 JSON 생성 → 로컬 채점을 진행할 수 있습니다.
현재 지원 범위는 공개 파일럿의 재현과 로컬 평가입니다. 공식 제출·순위 등록 절차는 아직 제공하지 않습니다.

## 데이터

| 구분 | 데이터 | 발화 / HOLD | 용도 |
|---|---|---:|---|
| 검증셋 | LiveKit 한국어 validation | 377 / 464 | 임계값·대기시간 선택 |
| 공개 파일럿 | MInDS-14 한국어 은행 문의 | 160 / 91 | 고정한 설정으로 별도 평가 |

EOT는 발화 종료, HOLD는 발화 중 멈춤을 뜻합니다. 별도 train set은 제공하지 않습니다.
저장소에는 파일럿 음성 160개와 자동 주석이 포함되어 있습니다. LiveKit 검증 음성은 포함하지 않으며, [공개 데이터셋](https://huggingface.co/datasets/livekit/eot-bench-data)에서 받을 수 있습니다.
선별 과정과 출처는 [데이터 안내](data/README.md)를 참고하세요.

## 비교 방법

| 방법 | 종료 판단에 사용하는 정보 |
|---|---|
| 무음 타이머 | 공통 VAD가 관찰한 무음 길이 |
| Smart Turn v3.2 CPU INT8 | 현재까지 들어온 음성의 최근 8초 |
| LiveKit v1-mini | 현재까지 들어온 음성의 최근 1.2초 |

세 방법은 같은 VAD와 입력 음성을 사용하며, 미래 음성이나 정답 주석을 입력으로 받지 않습니다.
모델 구현과 버전은 [베이스라인 안내](baseline/README.md)에 있습니다.

## 평가 기준

발화마다 첫 종료 선언 하나를 채점합니다.

- 조기 종료: 정답 EOT보다 먼저 종료를 선언한 경우
- 미검출: 정답 EOT 이후 4초까지 종료를 선언하지 않은 경우
- 정상 종료 지연: 정상 종료한 발화에서 `첫 선언 시각 − EOT`의 평균
- 전체 평균 손실: 정상 종료에는 실제 지연, 조기 종료·미검출에는 각각 4,000ms를 적용한 전체 발화 평균

순위는 전체 평균 손실이 낮은 순서입니다. 5%·10%는 검증셋에서 설정을 선택할 때의 조기 종료율 상한이며, 파일럿의 실제 오류율을 보장하지 않습니다. 미검출률 5% 이하 조건도 적용했습니다.

## 파일럿 결과

모든 행은 동일한 160개 발화를 평가했으며, 미검출은 0개입니다. 지연과 손실의 단위는 ms입니다.

| 검증 기준 | 방법 | 조기 종료율 | 정상 종료 지연 | 전체 평균 손실 |
|---|---|---:|---:|---:|
| 5% | Smart Turn v3.2 | 4.38% | 805.44 | 945.20 |
| 5% | LiveKit v1-mini | 4.38% | 866.93 | 1004.00 |
| 5% | 무음 타이머 | 3.13% | 931.92 | 1027.80 |
| 10% | LiveKit v1-mini | 6.25% | 439.04 | 661.60 |
| 10% | Smart Turn v3.2 | 6.88% | 482.36 | 724.20 |
| 10% | 무음 타이머 | 5.00% | 804.00 | 963.80 |

LiveKit v1-mini의 5% 설정은 125/160개(78.1%)를 1초 timeout으로 종료했습니다. 모델 점수와 제한 대기를 함께 적용한 결과입니다.
전체 수치는 [평가 결과](results/summary.json)에서 확인할 수 있습니다.

## 저장된 예측만 빠르게 확인하기

저장소를 내려받은 뒤, 루트 폴더에서 보관된 타이머 예측을 다시 채점할 수 있습니다. Python 3 표준 라이브러리만 필요합니다.

```bash
python3 evaluation/submission_score.py \
  --predictions results/baseline-pilot-timer-05.json \
  --references results/references.json \
  --output runs/example-score.json
```

이 명령은 저장된 예측을 다시 채점하며 모델 추론은 실행하지 않습니다. 결과는 `runs/example-score.json`과 턴별 CSV로 저장됩니다.

- 모델 준비·실제 추론·검증: [상세 실행 안내](docs/evaluation-guide.md)
- 내 예측의 JSON 형식과 채점: [예측 파일 안내](docs/submission-format.md)
- 평가 음성과 주석: [파일럿 데이터](data/pilot/)
- 데이터·모델 출처와 이용 조건: [라이선스](licenses/)

## 현재 범위와 한계

- 공개 음원에 자동 주석을 붙인 파일럿입니다. 사람이 검수한 정답이나 비공개 테스트 결과는 아닙니다.
- 주석 생성과 실행에 같은 Silero VAD를 사용하므로 평가 편향이 있을 수 있습니다.
- EOT 이후 4초까지 관찰하기 위해 부족한 후반 무음은 추론 버퍼에만 추가했습니다. 원본 WAV는 보존했습니다.
- 지연은 음성 시각 기준입니다. 모델 계산·네트워크 등을 포함한 실제 AI 비서의 응답시간은 아닙니다.
- 현재 실행기는 세 베이스라인의 고정 정책 재실행과 로컬 채점을 지원합니다. 새 모델 연결과 공식 리더보드 등록 절차는 아직 구현하지 않았습니다.
